# 사진기능사 필기 예상문제은행

사진기능사 필기 대비용 **예상문제 398문항**과, 브라우저에서 바로 풀고 채점하고
오답노트를 정리하는 문제풀이 페이지입니다.

## 바로 풀기

### 👉 <https://musicits.github.io/photo-exam/>

휴대폰에서도 그대로 됩니다. 설치도 회원가입도 필요 없습니다.
풀이 기록은 서버가 아니라 **각자의 브라우저 안에만** 저장됩니다.

## 할 수 있는 것

- **실전 모의고사** — 60문항 60분 카운트다운, 자동 채점.
  실제 시험과 같은 배분(과목당 20문항)과 전 과목 무작위 중에 고릅니다
- **과목별 연습** — 답을 고르면 그 자리에서 정답과 해설
- **단원별 연습** — 시중 교재 목차 그대로 8개 단원 중 골라서
- **오답 다시 풀기** — 틀린 문제만, 많이 틀린 문제부터. 맞히면 목록에서 빠집니다
- **보기별 풀이** — 문항에 따라 네 개 보기마다 왜 맞고 왜 아닌지가 답을 고른 뒤 붙습니다
- **오답노트** — 틀린 문제와 해설이 자동으로 쌓이고 메모를 적을 수 있음. `.md` 로 내보내기
- **`.md` 불러오기** — 내보낸 오답노트를 다른 기기에서 이어서 풀 수 있고,
  이 저장소의 단원별 문제집(`단원_*.md`)이나 직접 만든 문제 마크다운도 넣어 풀 수 있음
- **성적·취약분야** — 회차별 점수와 분야별 정답률. 정답률이 낮은 분야가 위로 옵니다

문제는 매번 섞이고 **아직 안 나온 것부터** 나옵니다.
회차를 거듭하면 398문항을 한 바퀴 다 보게 됩니다.
풀다가 나가면 저장할지 물어보고, 다음에 남은 시간과 고른 답 그대로 이어서 풀 수 있습니다.

## 짚어둘 것

**실제 기출문제가 아니라 예상문제입니다.** 공개된 기출(2015~2016년)과 이후 회차에서
반복되는 출제 포인트를 참고해 범위와 난이도를 가늠하고, 문제와 해설은 사진 이론
전 범위에서 새로 썼습니다. 기출 문항을 그대로 옮겨 실은 것은 하나도 없습니다.

출제기준 적용기간은 2024.1.1 ~ 2026.12.31이며, 필기 과목 구성은 그대로입니다.
최근으로 올수록 필름보다 **디지털 이미지 프로세싱과 사진 편집(포토샵)** 의 비중이
커지는 흐름을 반영해 그 부분을 두껍게 넣었습니다.

내용에 틀린 곳이 보이면 이슈로 알려 주세요. 공부에 쓰시는 것은 자유입니다.

## 오프라인으로 쓰려면

저장소를 내려받아

- macOS: `문제풀기 (macOS).command` 더블클릭
- Windows: `문제풀기 (Windows).bat` 더블클릭
- 또는 `index.html` 을 브라우저로 열기

문제 데이터가 HTML 안에 들어 있어 **파일 하나만 있으면** 됩니다.

## 문제를 더 추가하려면

문제 원본은 `parts/` 안의 JSON 파일에 있습니다.

```json
{"id":"S1-093","topic":"색채","q":"문제 내용","c":["보기1","보기2","보기3","보기4"],"a":1,"e":"해설"}
```

`a` 는 정답 보기의 번호(1~4), `topic` 은 `build.py` 의 `TOPIC_CHAPTER` 에 등록된
분야여야 하며 그 표를 보고 단원이 자동으로 붙습니다. 고친 뒤

```bash
python3 build.py                       # index.html·data·마크다운을 다시 만든다
python3 -m pytest tests -q
```

`build.py` 는 보기 순서를 회전시켜 **정답이 특정 번호에 몰리지 않도록** 맞춰 줍니다
(찍어서 맞히는 걸 막기 위해서입니다).
`index.html`, `data/questions.json`, `문제은행*.md`, `단원_*.md` 는 자동 생성물이니
직접 고치지 마세요. 고칠 곳은 `parts/*.json` 과 `quiz-template.html` 입니다.

`main` 브랜치의 `index.html` 이 그대로 GitHub Pages 로 서비스됩니다.
푸시하면 1분쯤 뒤에 반영됩니다.
