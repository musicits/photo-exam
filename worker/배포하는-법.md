# 오답노트 기기 잇기 — 올리는 법

한 번만 해 두면 됩니다. 도메인이 이미 클라우드플레어에 있으니 옮길 것은 없습니다.
`tools.musicits.com` 은 건드리지 않습니다. `sync.musicits.com` 이 새로 생길 뿐입니다.

준비물은 터미널 하나입니다. 맥은 스포트라이트(⌘+스페이스)에 `터미널`,
윈도우는 시작 메뉴에 `PowerShell` 을 치면 나옵니다.

## 1. 저장소 받기

이미 받아 두셨으면 그 폴더로 가시면 됩니다.

```bash
git clone https://github.com/musicits/photo-exam
cd photo-exam/worker
```

## 2. 클라우드플레어에 로그인

```bash
npx wrangler login
```

브라우저가 열리고 허락할지 묻습니다. `Allow` 를 누르면 터미널로 돌아옵니다.

## 3. 기록을 담아 둘 칸(KV) 만들기

```bash
npx wrangler kv namespace create NOTES
```

끝에 이런 줄이 나옵니다.

```
id = "0123456789abcdef0123456789abcdef"
```

`wrangler.toml` 을 열어 `여기에_KV_네임스페이스_ID` 를 지우고 그 값을 붙여 넣습니다.

## 4. 올리기

```bash
npx wrangler deploy
```

## 5. 됐는지 보기

브라우저에서 <https://sync.musicits.com/s/AAAAAA> 를 엽니다.

```json
{"error":"없는 코드입니다. 30일 넘게 안 쓰면 지워집니다."}
```

이 글이 보이면 잘 올라간 것입니다. 이제 사진기능사 화면의 [기기 잇기] 가 돕니다.
