# 오답노트 주고받기 — 배포하는 법

한 번만 해 두면 됩니다. 도메인이 이미 클라우드플레어에 있으니 옮길 것은 없습니다.

## 1. KV 만들기

```bash
cd worker
npx wrangler login          # 브라우저가 열리고 한 번 허락하면 끝
npx wrangler kv namespace create NOTES
```

마지막 줄에 `id = "..."` 가 나옵니다. 그 값을 `wrangler.toml` 의
`여기에_KV_네임스페이스_ID` 자리에 붙여 넣습니다.

## 2. 올리기

```bash
npx wrangler deploy
```

`sync.musicits.com` 주소가 자동으로 만들어집니다. DNS 를 손으로 건드릴 일은 없고,
`tools.musicits.com` 은 지금 그대로 둡니다.
